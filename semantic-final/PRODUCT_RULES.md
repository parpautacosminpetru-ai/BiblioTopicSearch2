# Reguli de produs — semantic explicit, verbatim

1. Similaritatea semantică este folosită doar pentru localizarea dovezii.
2. Textul rezultat este întotdeauna extras din sursă, fără parafrază.
3. O idee este afișată ca span complet START → END.
4. Nu se etichetează implicitul; numai conținutul explicit este acceptat.
5. Topicul/nodul tematic provine din harta locală a utilizatorului sau din interogarea explicită.
6. Categoriile sunt metadate de structură; nu generează interpretări.
7. Etichetele de compresie trebuie să fie substring-uri exacte ale dovezii.
8. Notebook-ul local întoarce dovezi, nu răspunsuri generate.
9. Nu există rezumare sau interpretare generativă.
10. Runtime-ul aplicației este offline și manifestul final nu cere permisiunea INTERNET.
